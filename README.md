# صفحه قیمت روزانه

یک صفحه وب فارسی که قیمت محصولات همه برندها را نشان می‌دهد و هر روز خودکار به‌روز می‌شود.
مشتری فقط یک لینک ثابت را باز می‌کند و می‌تواند بر اساس برند، کد و سایز جستجو کند،
قیمت را به ریال یا تومان ببیند و صفحه را PDF کند.

## راه‌اندازی (حدود ۱۰ دقیقه)

1. در گیت‌هاب یک مخزن **عمومی** (Public) بسازید، مثلاً `price-list`.
2. همه فایل‌های این پوشه را در آن آپلود کنید (پوشه `.github` را هم فراموش نکنید).
3. در مخزن: **Settings ← Pages ← Source** را روی **GitHub Actions** بگذارید.
4. در **Settings ← Actions ← General ← Workflow permissions** گزینه **Read and write permissions** را انتخاب و ذخیره کنید.
5. به تب **Actions** بروید، «به‌روزرسانی قیمت‌ها» را باز کنید و **Run workflow** بزنید.
6. بعد از یکی دو دقیقه آدرس صفحه در همان‌جا ظاهر می‌شود:
   `https://<نام‌کاربری>.github.io/price-list/`

از این به بعد هر روز حدود ساعت ۵:۳۰ صبح تهران خودکار به‌روز می‌شود.

## اگر گیت‌هاب نتوانست قیمت‌ها را بگیرد

سرور قیمت‌ها ممکن است درخواست از خارج ایران را رد کند. در این صورت در تب Actions
مرحله «دریافت قیمت‌ها» قرمز می‌شود، ولی صفحه با آخرین قیمت‌های ذخیره‌شده منتشر می‌شود.
راه‌حل: قیمت‌ها را روی کامپیوتر خودتان بگیرید و به گیت‌هاب بفرستید.

1. در **Settings ← Secrets and variables ← Actions ← Variables** متغیری با نام `LOCAL_MODE` و مقدار `true` بسازید.
2. روی کامپیوتر پایتون و گیت را نصب کنید، مخزن را `git clone` کنید و یک‌بار `pip install -r requirements.txt` بزنید.
3. فایل `update_and_push.bat` را با **Task Scheduler** ویندوز هر روز اجرا کنید
   (Create Basic Task ← Daily ← Start a program ← مسیر همین فایل).

## تنظیمات ظاهری

فایل `docs/config.json` را ویرایش کنید: عنوان صفحه، شماره تماس و متن زیر صفحه.
اگر شماره تماس بنویسید، دکمه «تماس» برای مشتری ظاهر می‌شود.

## اجرای دستی روی کامپیوتر

```
pip install -r requirements.txt
python update_data.py                 قیمت‌ها را در docs/data/prices.json می‌نویسد
python -m http.server 8000 -d docs    صفحه را در http://localhost:8000 باز کنید
python sgp_prices.py                  اکسل جدا برای هر برند (پوشه prices)
```

## نکات

- **داده نمونه:** تا اولین به‌روزرسانی موفق، صفحه قیمت‌های نمونه (DEMO) با یک هشدار نشان می‌دهد.
- **خطای یک برند:** قیمت قبلی همان برند حفظ می‌شود و بالای صفحه به مشتری اطلاع داده می‌شود.
- **تغییر قیمت:** از اجرای دوم به بعد، کنار هر محصول درصد افزایش یا کاهش و نشان «جدید» تا ۱۴ روز دیده می‌شود.
- **عمومی بودن:** Pages رایگان فقط برای مخزن عمومی کار می‌کند، پس قیمت‌ها برای همه قابل دیدن است.
- **دسترسی از ایران:** اگر `github.io` برای مشتری‌ها باز نشد، همین پوشه `docs` را روی هر هاست ساده هم می‌توان گذاشت.
